# Картридж — Mega Drive в браузере телефона

Офлайн-PWA для Android: эмулятор Sega Mega Drive / Genesis (EmulatorJS + ядро Genesis Plus GX),
полка игр, экранный геймпад и автосохранение «с того же места». Игры в комплект не входят —
ты загружаешь свои ROM-файлы прямо с телефона.

## Как выложить (5 минут, бесплатно)

PWA должна открываться по HTTPS, поэтому её нужно один раз выложить на хостинг. Проще всего — GitHub Pages.

1. Создай на GitHub новый **публичный** репозиторий, например `kartridzh`.
2. В репозитории нажми **Add file → Upload files** и перетащи туда **всё содержимое** этой папки
   (не саму папку, а то, что внутри: `index.html`, `emulatorjs/`, `icons/` и т. д.). Нажми **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)`. **Save**.
4. Через минуту сайт будет по адресу `https://<твой-логин>.github.io/kartridzh/`.

Альтернатива без GitHub: https://app.netlify.com/drop — перетащить папку в окно браузера.

## Как поставить на телефон

1. Открой ссылку в **Chrome** на Android.
2. Нажми «Установить» в шапке (или меню ⋮ → «Добавить на главный экран» / «Установить приложение»).
3. Приложение открывается на весь экран и дальше работает **без интернета**.

## Откуда взять ROM

Используй свои копии игр. Например, в Steam-сборнике *SEGA Mega Drive & Genesis Classics*
файлы лежат в папке `steamapps/common/Sega Classics/uncompressed ROMs`
(Sonic 1 — `SONIC_W.68K`, Sonic 2 — `SONIC2_W.68K`, Sonic 3 & Knuckles — `Sonic_Knuckles_wSonic3.bin`).
Скопируй нужные файлы на телефон (USB, Google Drive, Telegram «Избранное») и нажми «Добавить игру».

Поддерживаются `.md .bin .gen .smd .68k .zip .7z`.

## Что умеет

- Полка игр с автоматическим названием из заголовка картриджа; переименование и удаление через «⋯».
- Автосохранение каждые 30 секунд и при сворачивании/выходе — игра продолжается с того же места.
  «⋯ → Начать с начала» — запуск без автосейва.
- Внутриигровые сохранения (например, слоты Sonic 3) и сейв-стейты из меню эмулятора хранятся в браузере.
- Экран не гаснет во время игры, ориентация — альбомная.
- Работает офлайн: приложение и ядро эмулятора (~3,5 МБ) кэшируются при первом открытии.
- Bluetooth-геймпад подхватывается автоматически, кнопки настраиваются в меню эмулятора (иконка геймпада).

Выход из игры — кнопка ✕ в левом верхнем углу или системный жест «назад».

## Важно

- Игры и сохранения живут в хранилище Chrome на телефоне. Если очистить данные сайта
  или удалить приложение — полку придётся загрузить заново.
- Если поменяешь файлы приложения, увеличь `VERSION` в `sw.js` (например, `kartridzh-v2`),
  иначе телефон будет показывать старую версию из кэша.

## Состав

| Файл | Назначение |
| --- | --- |
| `index.html`, `shelf.js` | полка игр, загрузка ROM |
| `play.html`, `play.js` | экран игры, настройки эмулятора, автосейв |
| `db.js` | хранение ROM и автосейвов в IndexedDB |
| `sw.js`, `manifest.webmanifest` | офлайн-кэш и установка PWA |
| `emulatorjs/` | EmulatorJS 4.2.3 (GPL-3.0) и ядро Genesis Plus GX, только Mega Drive |

EmulatorJS — https://github.com/EmulatorJS/EmulatorJS (GPL-3.0, лицензия в `emulatorjs/LICENSE`).
Genesis Plus GX — https://github.com/ekeeke/Genesis-Plus-GX (некоммерческая лицензия, личное использование).
